# PrivacySek — Privacy Intelligence Platform

Enterprise privacy management and data protection platform connecting people, data, systems, processing, consent, rights, risk, and regulatory context from discovery to enforcement.

## Features

- **Global Regulatory Landscape**: 3D interactive globe and regulatory knowledge graph for DPDPA, GDPR, CCPA, and global privacy laws.
- **Privacy Lens**: Multi-dimensional view of data currents across Data, Privacy, Risk, DPO, and Jurisdiction lenses.
- **Connected Tree Architecture**: Interactive tree diagram mapping global compliance, automated discovery, lifecycle rights, and real-time enforcement.
- **Interactive Regulation Flip Cards**: Direct comparison and operational coverage for major data privacy frameworks.
- **Decision Engine & Data Discovery**: Continuous scanning, ROPA automation, DSAR workflows, and policy enforcement.

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:8080/` in your browser.

### Build for Production

```bash
npm run build
```
